# Hiring Challenges — Robotics Engineer @ AICI GmbH

This repository contains the take-home coding challenges for candidates
applying to the Robotics Engineer position at **AICI GmbH**.

## Submission structure

Submit the whole repository as-is, with your solution code added and the
`results/` and `write-ups/` folders filled in:

```
hiring_challenges/
├── .gitignore
├── README.md
├── maps/                        # shared sample maps used by both challenges
├── explore_and_return/          # challenge code — your solution goes here
├── viewpoint_planning/          # challenge code — your solution goes here
├── results/
│   ├── explore_and_return/
│   │   └── <sample>/            # e.g. 1 — report.yaml, map.pgm/yaml
│   └── viewpoint_planning/
│       └── <sample>/            # e.g. 3 — coverage_report.png/json
└── write-ups/
    └── <your-name>-<challenge>.md
```

Please submit:

- **This repository, updated** with your solution code committed on top of
  the provided scaffolding.
- **`results/<challenge>/<sample>/`** — the result artifacts generated by the
  challenge's own runner, one folder per sample map you ran your final
  solution against.
- **`write-ups/`** — one write-up per challenge you attempted, based on
  [`write-ups/TEMPLATE.md`](write-ups/TEMPLATE.md).

See each challenge's own README for full setup, task, and scoring details.
